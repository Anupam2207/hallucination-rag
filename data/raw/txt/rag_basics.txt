Retrieval-Augmented Generation (RAG) is an artificial intelligence framework that combines information retrieval with large language model generation. Instead of relying only on the knowledge stored in model parameters, a RAG system retrieves relevant external information and uses it as context before generating a response.

The RAG architecture was introduced by Patrick Lewis and colleagues in 2020 in the paper "Retrieval-Augmented Generation for Knowledge-Intensive NLP Tasks." The goal of RAG is to improve factual accuracy and reduce hallucinations in language model outputs.

A typical RAG pipeline consists of several stages. First, a user submits a query. The system converts the query into embeddings and searches a knowledge base or vector database for relevant documents. The retrieved documents are then provided to a language model as context. Finally, the language model generates a grounded response using both the query and the retrieved evidence.

RAG systems commonly use dense retrieval methods such as DPR (Dense Passage Retrieval), semantic embeddings generated by transformer models, and vector databases such as ChromaDB, FAISS, Pinecone, or Weaviate. Some systems also combine dense retrieval with sparse retrieval methods such as BM25 to improve search performance.

One of the main advantages of RAG is improved factual reliability. Because responses are grounded in retrieved evidence, the system can provide more accurate and up-to-date information than a standalone language model. RAG is widely used in enterprise search, question answering systems, document assistants, research assistants, customer support systems, and knowledge management applications.

RAG is often used to mitigate hallucinations in large language models. Hallucination occurs when a model generates information that is factually incorrect, fabricated, or unsupported by evidence. By retrieving relevant external knowledge before generation, RAG helps reduce the likelihood of unsupported claims.

When evaluating RAG systems, common metrics include retrieval precision, retrieval recall, support score, answer faithfulness, factual consistency, hallucination rate, and answer relevance. Some advanced systems also use Natural Language Inference (NLI) models to verify whether generated claims are supported by retrieved evidence.

It is important not to confuse retrieval and generation. Retrieval identifies relevant information from external sources, while generation produces natural language responses. A RAG system combines both processes to generate evidence-grounded answers.

Key concepts related to RAG include embeddings, semantic search, vector databases, dense retrieval, sparse retrieval, reranking, evidence verification, hallucination detection, and factual correction.
