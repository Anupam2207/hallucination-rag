# ChromaDB Local Vector Store

ChromaDB is a lightweight local vector database used to store embeddings and retrieve nearby passages. It can persist indexes on disk, which makes it convenient for small prototypes that run on a laptop.

In this dataset, ChromaDB appears only in this note so that queries about vector stores do not compete with unrelated documents. For production systems, the quality of the retrieved chunks still depends on clean text, useful metadata, and careful chunk sizes.
